# K-Nuurrooster — Verlof & Uurrooster Tool voor KNeindhout

Een webapplicatie voor het beheren van werkroosters en verlofplanning,
gebouwd voor KNeindhout. Het project vervangt een eerder Excel-gebaseerd
systeem door een overzichtelijke, browser-gebaseerde tool.

## Wat doet deze tool?

- **Rooster** — overzicht van werkschema's per medewerker
- **Kalender** — visuele weergave van planning en verlof
- **Verlofrechten** — bijhouden van opgebouwde en opgenomen verlofdagen
- **Saldo** — overzicht van resterende uren/dagen
- **Planning** — indeling van medewerkers over shiften
- **Medewerkers** — beheer van personeelsgegevens

## Status

🔧 **In ontwikkeling / klaar voor gebruik vanaf volgend werkjaar.**

Momenteel werkt de tool standalone (alle data lokaal in de browser). Een
toekomstige uitbreiding voorziet live-synchronisatie via Firebase, naar het
voorbeeld van het [rendementstool-project](#), zodat meerdere gebruikers
tegelijk met actuele data kunnen werken.

## Technologie

- HTML / CSS / JavaScript
- Eén overzichtelijk bestand (`index.html`), met tabbladen per functie
- Gehost via GitHub Pages voor snelle, gratis toegang

## Achtergrond

Dit project ontstond vanuit de nood aan een moderner alternatief voor een
verouderd Excel-systeem bij KNeindhout, met als doel: minder handmatig
werk, minder fouten, en een duidelijker overzicht voor zowel medewerkers
als planners.
